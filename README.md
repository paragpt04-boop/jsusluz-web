# JsusLuz Web

Simulador web educativo de consumo y costo eléctrico.

## Características
- Simulación por potencia, horas de uso y costo por kWh.
- Desglose día por día de 1 a 30 días.
- Consumo y costo diario y acumulado.
- Diseño responsive con animaciones y tooltips contextuales.
- Páginas de privacidad, términos, contacto y metodología.
- Espacios preparados para futura integración publicitaria.
- Sitio estático: HTML, CSS y JavaScript, ideal para Cloudflare Pages.

## Estructura
- `index.html`: aplicación principal.
- `assets/css/styles.css`: interfaz responsive.
- `assets/js/app.js`: motor del simulador.
- `como-funciona.html`: explicación de cálculos.
- `privacidad.html`, `terminos.html`, `contacto.html`: páginas informativas.

## Publicidad
Los bloques visuales de publicidad son placeholders. No contienen todavía código de Google AdSense. El script y los IDs reales deben añadirse únicamente después de disponer de una cuenta/configuración válida.

## Despliegue
El proyecto no necesita build ni backend. Puede publicarse directamente desde la rama `main` en un hosting de sitios estáticos como Cloudflare Pages.
